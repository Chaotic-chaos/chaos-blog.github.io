测试新的博客书写工具

Feb 3, 2026· Chaos

Intro

  • 时隔三年，不小心在整理git仓库的时候发现了这份源码；
  • 原来当时搭建的Blog依旧在稳定的运行，躺在众多互联网内容的一个小小角落；（说不定也曾经被训进某个 LLM 🙈）
  • 恰逢今天在V2EX 上刷到这个新的静态博客书写工具，解决了当时最阻挡写博客脚步的刚需：Meta 信息的编辑和 git 仓库的操作导致的写作前后处理流程过长；
  • 惊叹、反思，在有了痛点的时候最好多想一步，看能否把痛点转化成需求，再通过现在如此方便的 Coding 方式来实现需求，解决痛点！
